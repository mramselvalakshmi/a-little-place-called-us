# A Little Place Called Us ♡

A mobile-friendly romantic mini website made with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure
- `style.css` — soft-pink styling and animations
- `script.js` — envelope interaction, letter, 11 reasons and navigation

## Run it on your computer
1. Download and extract `a-little-place-called-us.zip`.
2. Open the extracted folder in VS Code.
3. Open `index.html` in your browser (double-click it), or use the VS Code Live Server extension.
4. To personalise the message, edit the `letter` text and `reasons` list near the top of `script.js`.

No backend, database, API key or paid service is required. Google Fonts needs an internet connection; the page still works with fallback fonts offline.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a **new public repository** named `a-little-place-called-us`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root (not inside another folder).
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait a minute or two. GitHub will show your public website URL in the Pages section.
7. Open the URL on your phone to test it, then send the link to him.

## Before sharing
- Read the letter once and change any line that doesn't sound like you.
- Replace general reasons with real details only you two share.
- Test the envelope and all 11 cards on your phone.
- The site is public to anyone with the link when hosted in a public repository. Don't add private information or photos unless you're comfortable sharing them.
